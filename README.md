# 🚌 Safar Beats (सफ़र बीट्स)

> **Non-Stop Highway Music Experience · Real Road Acoustics · Dual Musical Air Horns**

A high-fidelity, cinematic vehicle-themed web music experience celebrating Indian bus drivers, night-time car cruisers, and highway motorcyclists navigating NH 48 Delhi—Mumbai with authentic air horns and diesel engine acoustics.

---

## 🌟 Key Highlights & Features

### 1. 📢 Authentic Dual Musical Air Horns ("हॉर्न ओके प्लीज़")
- True Indian interstate multi-tone pressure horns (*Horn #1 & Horn #2*).
- Plays sequentially one by one upon trigger.
- Accompanied by acoustic bass vibration and vehicle bumper glow effects.
- Direct keyboard shortcut: press <kbd>H</kbd>.

### 2. ☕ Chai for the Driver
- Serve a steaming glass of roadside dhaba *cutting chai* to the driver.
- Plays authentic roadside chai pouring audio with a cheerful driver energy toast!

### 3. 🔁 Continuous Endless Loop Playback
- Music loops seamlessly without any interruption.
- Audio engine is pre-configured to loop by default for non-stop interstate night driving.

### 4. 🚗 Journey Mode Switcher
- **🚗 DRIVE**: Driver's cockpit view with direct steering perspective.
- **💺 RIDE**: Passenger side-window view with scenic highway panoramas.
- **Category Switcher**: Instant switch between **BUS**, **CAR**, and **BIKE** audio worlds.

### 5. 🎛️ Highway Ambience Mixer
- Dual-channel audio engine combining high-fidelity master music with real engine idle, highway tire roar, and night rain streaks.

### 6. 📺 Zen Pure Video Mode
- Scroll down past the hero or press <kbd>V</kbd> to enter 100% full-screen road video immersion.

## ⌨️ Keyboard Controls

| Key | Action |
|:---:|:---|
| <kbd>Space</kbd> | Toggle Play / Pause |
| <kbd>H</kbd> | Honk Musical Air Horns (Cycles Horn #1 & #2) |
| <kbd>←</kbd> / <kbd>→</kbd> | Seek Backward / Forward 5 seconds |
| <kbd>V</kbd> | Toggle Pure Video / Zen Mode |
| <kbd>Q</kbd> | Open Track Queue & Playlist Drawer |
| <kbd>T</kbd> | View Bus Boarding Ticket & QR Code |
| <kbd>M</kbd> | Toggle Highway Ambience Mute |
| <kbd>Esc</kbd> | Close any open modal / Exit Zen mode |

## 🚀 Getting Started

### Prerequisites
- Node.js `18.0.0` or higher
- npm, yarn, or pnpm

### Installation

```bash
# Clone the repository
git clone https://github.com/your-username/safar-beats.git

# Navigate into project directory
cd safar-beats

# Install dependencies
npm install
```

### Local Development

```bash
# Start Vite development server
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

### Production Build

```bash
# Build production bundle
npm run build

# Preview production build locally
npm run preview
```

The optimized static assets will be output to the `dist/` directory, ready to deploy to any modern static hosting service or container.
